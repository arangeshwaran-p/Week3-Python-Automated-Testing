# Student Result Analyzer

## Project Description
A Python application that calculates student total marks, average, grade, and pass or fail status.

## Features
- Calculate total marks
- Calculate average marks
- Assign grades
- Check pass or fail
- Analyze complete student results

## Technologies
- Python 3.14
- Pytest

## Installation
py -m pip install -r requirements.txt

## Run Application Tests
py -m pytest -v
